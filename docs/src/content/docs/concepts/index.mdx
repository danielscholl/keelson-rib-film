Four ideas carry the rib. A **library** holds series of pieces, each a folder
with a manifest. The **production line** turns a manifest into a cut. **Gates**
decide who looks before the next step. A **look** and a **voice**, set once per
series, keep every piece in it recognizably the same. For the harness ideas these
sit on (workflows, approval nodes, ribs), see Keelson's
[concepts](https://keelsonrib.ai/docs/concepts/).
