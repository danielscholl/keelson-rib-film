The rib is early. These are known gaps, not promises of a date.

## film-revise

The cut gate captures your notes, and the gate message says to reply with notes
for `film-revise`. That workflow, which turns numbered notes into manifest and
board changes and cuts again, isn't in the rib yet. Today, give the notes to the
agent in chat and run `film-cut` again.

## A director agent

The method is written for one agent reading `film_guide`. A dedicated director
(a contributed agent persona that plans angles and storyboards and holds the
series ledger) would make the planning steps more consistent across providers.

## A board surface

The rib has no tab in Keelson. A board showing each series, its pieces by stage,
and the cut waiting at a gate would replace asking for `film_status`.

## Deterministic measurement

Loudness and autoscan results can differ slightly between runs on the same cut,
so the reviewer's thresholds carry some tolerance. Making the measurements
repeatable would let the review page be compared across rounds exactly.
