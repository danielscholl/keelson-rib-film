Each guide gets one job done and assumes the rib's [concepts](../concepts/).
**The method** is the craft half: how a good short is planned, drawn, voiced,
mixed and reviewed. Agents read the same pages through `film_guide`. To work on
the rib's source, see
[CONTRIBUTING.md](https://github.com/danielscholl/keelson-rib-film/blob/main/CONTRIBUTING.md).
